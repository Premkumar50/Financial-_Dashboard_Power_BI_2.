# 📊 Financial Dashboard – Power BI (Project 2)

## 📌 Project Overview

This is my second Power BI project, created while learning data visualization and financial data analysis. The dashboard presents financial data to help understand revenue, expenses, profit, and business performance.

## 🛠️ Tools Used

* Microsoft Power BI
* Microsoft Excel

## 📂 Project Files

* `Financial Dashboard (Power BI).pbix` – Power BI dashboard file.
* `financial_dataset.xlsx` – Raw dataset used for the analysis.
* `Image Power BI.png` – Dashboard screenshot.

## 📈 Key Analysis

* Revenue, expenses, and profit analysis.
* Regional and product performance.
* Channel-wise financial analysis.
* Customer metrics and satisfaction.
* Financial trends over time.

## 🚀 How to Use

1. Download the `.pbix` file and Excel dataset.
2. Open the Power BI file in Microsoft Power BI Desktop.
3. Update the dataset path if required.
4. Refresh the data and explore the dashboard.
